# Dataset Guide

This project ships with local synthetic cybersecurity datasets for Week 2 pipeline development.

## Available datasets
- NSL-KDD: synthetic network intrusion samples under datasets/raw/nsl_kdd/train.csv
- CICIDS2017: synthetic traffic samples under datasets/raw/cicids2017/cicids.csv
- PhishTank: synthetic phishing URLs under datasets/raw/phishtank/phishing_urls.csv

## Data manager
Use the dataset manager to discover, validate, and prepare datasets through the Python API or REST endpoints.
