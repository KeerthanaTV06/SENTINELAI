# Features and Roadmap

This file documents the planned features for Days 1–7 (Day 1 is scaffolded in this repo).

Day 1
- Project scaffolding
- Docker Compose for Kafka, Zookeeper, Elasticsearch, Kibana
- Minimal FastAPI app with health endpoints

Day 2
- Datasets: NSL-KDD, CICIDS2017, PhishTank
- Dataset loader and schema validation

Day 3
- Streaming pipeline: CSV -> Kafka producers -> topics -> consumer -> Elasticsearch

Day 4
- Feature engineering pipeline, Parquet feature store, DVC tracking

Day 5
- Data validation using Great Expectations, EDA notebooks

Day 6
- LSTM intrusion detection model (PyTorch)

Day 7
- RandomForest and XGBoost experiments, model selector, MLflow tracking
