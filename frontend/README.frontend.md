SENTINEL-AI Frontend

This folder contains a Vite + React + TypeScript frontend for the SENTINEL-AI backend.

Quickstart
1. cd frontend
2. npm install
3. Copy environment variables (optional):
   create a .env file with VITE_API_URL=http://localhost:8000
4. npm run dev

Build
- npm run build

Notes
- Tailwind CSS is configured. Ensure postcss and autoprefixer are installed.
- The frontend expects backend API routes under http://localhost:8000/api and /api/v1
